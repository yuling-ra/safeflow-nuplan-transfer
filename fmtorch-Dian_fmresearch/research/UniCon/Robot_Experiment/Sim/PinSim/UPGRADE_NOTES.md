## 主要变化

### 1. 决策变量大幅减少
- **原版 (Euler)**: ~10,500 个变量 (7×300×5)
- **样条版**: ~1,344 个变量 (7×64×3)
- **减少**: 87%

#### b. 变量结构变化
```python
# 原版：N=300 个节点
q, v, a, tau, th (每个节点)

# 样条版：K=64 个结点 (knots)
```

#### c. 约束方式变化
```python
# 原版：半隐式欧拉积分
v_{k+1} = v_k + a_k * dt
q_{k+1} = q_k + v_{k+1} * dt

# 样条版：配点法 (collocation)
# 在 Gauss 点 [0.21, 0.79] 处强制动力学
tau = M(q)·a + h(q,v)  # 扭矩约束
```

### 3. 输出数据格式

#### 致密轨迹 (500Hz, 6806 样本)
- `t`, `q`, `dq`, `ddq`, `tau` - 与原版兼容

#### 新增：结点数据
- `knots_q`, `knots_dq`, `knots_ddq` - 64 个优化结点

### 10. 技术细节

#### 五次 Hermite 基函数
```
H₀₀(s) = 1 - 10s³ + 15s⁴ - 6s⁵    (位置, 起点)
H₁₀(s) = s - 6s³ + 8s⁴ - 3s⁵       (速度, 起点)
H₂₀(s) = 0.5s² - 1.5s³ + 1.5s⁴ - 0.5s⁵  (加速度, 起点)
H₀₁(s) = 10s³ - 15s⁴ + 6s⁵        (位置, 终点)
H₁₁(s) = -4s³ + 7s⁴ - 3s⁵         (速度, 终点)
H₂₁(s) = 0.5s³ - s⁴ + 0.5s⁵       (加速度, 终点)
```

#### Gauss-Legendre 配点
```
s₁ = 0.211324865405187  (约 0.21)
s₂ = 0.788675134594813  (约 0.79)
```

这两个点在 [0,1] 区间上对多项式积分最优。
