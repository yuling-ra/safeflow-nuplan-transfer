# 相位锁定轨迹跟踪升级说明

## 问题诊断

原始代码的轨迹跟踪效果不佳，主要表现为：
1. **相位滞后**：实际轨迹落后于期望轨迹
2. **振幅衰减**：实际轨迹幅度小于期望轨迹
3. **"粘不住"8字轨迹**：无法精确跟随复杂轨迹

### 根本原因

1. **过强的滤波/限幅** → 高频修正被抑制
   - `QDOT_LP_ALPHA=0.85` 强滤波
   - `TAU_LP_ALPHA=0.90` 强力矩滤波
   - 保守的扭矩斜率限幅 `TAU_SLEW`
   
2. **SVD速度缩放过于保守** → 人为降速
   - 最小奇异值稍小就打到 0.25~0.6 倍速
   
3. **腕关节力矩限制过严** → 饱和压缩幅度
   - `TAU_LIM = [85,85,85,85,20,20,20]` 腕部仅20Nm
   
4. **缺乏锁相机制** → 时间表固定，无法消除沿切向滞后
   - 使用固定 `t + phase0` 走表
   - 只有位置P/PD，没有相位反馈

5. **带宽不足**
   - 刚度增益偏低
   - 阻尼过大

### 5. **核心改进：相位锁定（Phase-Lock）控制**

#### 原理
- 不再使用固定时间表 `τ = t + phase0`
- 引入相位状态 `s`，根据**沿切向的位置误差**动态调整相位速度
- 落后则加速，超前则减速，实现"锁相"效果

#### 实现

```python
# 相位锁定参数
K_PHASE = 8.0    # 相位修正增益（3~20可调）
LP_S = 0.2       # 相位速度平滑系数

# 初始化相位状态
s = phase0
s_dot_prev = omega

# 修改轨迹生成函数，接收相位而非时间
def desired_pose_from_phase(s):
    # ... 使用 s 代替 (t + phase0)
    return x, v, R, tang_vec  # 额外返回切向速度向量

# 主循环中
for i in range(N):
    # 1) 从当前相位生成期望位姿
    x_des, v_des, R_des, tang_vec = desired_pose_from_phase(s)
    
    # 2) IK + 关节PD + 前向动力学（同之前）
    # ...
    
    # 3) 计算当前实际末端位置
    ee = data.oMf[ee_fid].translation
    
    # 4) 计算沿切向的位置误差
    e_xyz = x_des - ee
    t_hat = tang_vec / norm(tang_vec)
    e_tan = dot(e_xyz, t_hat)  # 落后为正，超前为负
    
    # 5) 相位速度修正
    s_dot_cmd = omega + K_PHASE * e_tan  # 落后→加速，超前→减速
    s_dot = (1-LP_S)*s_dot_cmd + LP_S*s_dot_prev  # 平滑
    s += s_dot * dt
    s_dot_prev = s_dot
```

## 参数调优指南

### 如果出现震荡
1. 降低刚度：`Kp_j` 减小10-20%
2. 增加阻尼：`Kv_j` 系数从1.0提到1.2
3. 降低相位增益：`K_PHASE` 从8降到5

1. 提高刚度：`kp_pos` 提到30+
2. 提高关节刚度：`Kp_j` 各增加20%
3. 提高相位增益：`K_PHASE` 从8提到12-15

1. 开启力矩裁剪：`USE_TAU_CLIP = True`
2. 降低腕部限制：`TAU_LIM[-3:]` 从40降到30
3. 降低刚度：整体减小`Kp_j`

## 技术细节

### 相位锁定原理

传统方法：
```
τ = t + phase0  （固定走表）
x_des(τ), v_des(τ)  → IK → 控制
```
- 问题：即使控制器再努力，沿切向的滞后无法被消除（只有位置反馈）

相位锁定方法：
```
s = s + s_dot*dt  （动态相位）
s_dot = ω + K_PHASE * e_tan  （相位速度修正）
x_des(s), v_des(s)  → IK → 控制
```
- 效果：沿切向的误差 → 相位加/减速 → 自动对齐轨迹

类比：
- 传统方法 = 固定速度的传送带 + 位置控制
- 相位锁定 = 可变速传送带 + 位置控制 + 速度同步

### 为什么是切向误差？

位置误差 e_xyz 可分解为：
- **法向误差**：垂直于轨迹的偏差 → 由位置反馈 kp_pos 处理
- **切向误差**：沿轨迹的超前/滞后 → 由相位锁定处理

```
e_tan = e_xyz · t̂  （投影到切向）
```
