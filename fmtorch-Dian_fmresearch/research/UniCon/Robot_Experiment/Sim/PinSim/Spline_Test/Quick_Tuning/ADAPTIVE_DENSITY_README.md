# B样条自适应密度调优工具

## 功能概述

这个增强版的调优工具添加了**自适应控制点密度**功能，允许您在轨迹的特定时间段内增加更多的控制点，从而在关键区域获得更高的重建精度。

## 新增功能

### 1. 幂函数自适应密度控制

使用幂函数来控制控制点的分布密度：

```python
density_boost(t) = height * exp(-decay_rate * ((t - center)/width)^power)
```

### 2. 可配置参数

在 `quick_tune.py` 顶部的配置区域，您可以调整以下参数：

#### 基线控制点数量
```python
M_Q_BASE = 64     # Position基线控制点
M_DQ_BASE = 64    # Velocity基线控制点  
M_TAU_BASE = 64   # Torque基线控制点
```

#### 自适应密度开关
```python
ADAPTIVE_Q = True    # 为Position启用自适应密度
ADAPTIVE_DQ = True   # 为Velocity启用自适应密度
ADAPTIVE_TAU = True  # 为Torque启用自适应密度
```

#### 幂函数参数
```python
POWER_PARAMS_Q = {
    'center': 0.5,      # 峰值中心位置 [0,1]，归一化时间
    'width': 0.3,       # 峰值宽度（越大影响范围越广）
    'height': 1.0,      # 峰值处的密度倍增（1.0 = 在峰值处翻倍）
    'decay_rate': 3.0,  # 衰减速率（越大衰减越陡）
    'power': 2,         # 衰减形状的幂次（2 = 类高斯，更高 = 更平的顶部）
}
```

### 3. 新的可视化图表

运行脚本后会生成 **`adaptive_density_analysis.png`**，显示：

- **横轴**：实际时间步（timestep）
- **纵轴**：控制点密度（ctrl pts / time）
- **蓝色区域**：基线均匀分布的密度
- **红色区域**：由幂函数增加的额外密度
- **统计信息**：显示最大增强位置和增强量

## 使用方法

### 快速开始

1. **调整基线控制点**：先设置一个较低的基线值（如32-64）
   
2. **定位关键区域**：查看您的轨迹，找到需要更高精度的时间段
   - 例如：快速转向区域、碰撞前后、复杂动作等

3. **配置幂函数**：
   ```python
   POWER_PARAMS_Q = {
       'center': 0.3,      # 如果关键区域在轨迹前30%处
       'width': 0.2,       # 影响轨迹的20%时间范围
       'height': 2.0,      # 在峰值处增加3倍控制点（1+2=3x）
       'decay_rate': 5.0,  # 快速衰减到基线
       'power': 2,         # 平滑的高斯型衰减
   }
   ```

4. **运行并查看结果**：
   ```bash
   python quick_tune.py
   ```

5. **检查密度分析图**：
   - 查看 `adaptive_density_analysis.png`
   - 确认红色增强区域在您预期的位置
   - 查看 "Max Boost" 值确认峰值增强量

### 参数调优指南

#### `center` - 峰值中心
- **范围**: 0.0 到 1.0
- **含义**: 在归一化时间轴上，密度峰值的中心位置
- **调整技巧**:
  - 0.0 = 轨迹开始
  - 0.5 = 轨迹中间
  - 1.0 = 轨迹结束
  - 可以为 q、dq、tau 设置不同的中心

#### `width` - 峰值宽度
- **范围**: 0.05 到 0.5（推荐）
- **含义**: 控制增强区域的宽度
- **效果**:
  - 小值（0.1）= 窄而尖的峰，仅影响很小的时间范围
  - 大值（0.4）= 宽而平的峰，影响较大的时间范围

#### `height` - 峰值高度
- **范围**: 0.0 到 5.0（推荐）
- **含义**: 在峰值处相对于基线的密度增加倍数
- **效果**:
  - 0.0 = 无增强，等同于禁用
  - 1.0 = 在峰值处密度翻倍（总密度 = 基线 × 2）
  - 2.0 = 在峰值处密度三倍（总密度 = 基线 × 3）
  - **注意**: 过高的值会导致总维度急剧增加

#### `decay_rate` - 衰减率
- **范围**: 1.0 到 10.0（推荐）
- **含义**: 从峰值衰减到基线的速度
- **效果**:
  - 小值（1.0-2.0）= 缓慢衰减，影响范围广
  - 大值（5.0-10.0）= 快速衰减，影响范围窄而集中

#### `power` - 幂次
- **范围**: 1 到 4（推荐）
- **含义**: 控制衰减曲线的形状
- **效果**:
  - 1 = 指数衰减
  - 2 = 类高斯衰减（推荐，平滑且常用）
  - 3-4 = 更平的顶部，更陡的边缘

## 实际应用示例

### 示例1：轨迹起始阶段需要高精度

```python
M_Q_BASE = 48

POWER_PARAMS_Q = {
    'center': 0.15,      # 前15%
    'width': 0.2,        # 覆盖0-35%时间段
    'height': 1.5,       # 峰值处2.5倍密度
    'decay_rate': 4.0,   # 快速衰减
    'power': 2,
}
```

### 示例2：轨迹中间有复杂动作

```python
M_Q_BASE = 40

POWER_PARAMS_Q = {
    'center': 0.6,       # 60%处
    'width': 0.25,       # 覆盖35-85%时间段
    'height': 2.0,       # 峰值处3倍密度
    'decay_rate': 3.0,   # 中等衰减
    'power': 2,
}
```

### 示例3：全局均匀分布（禁用自适应）

```python
ADAPTIVE_Q = False
ADAPTIVE_DQ = False
ADAPTIVE_TAU = False

# 或者等价地：
POWER_PARAMS_Q = {
    'center': 0.5,
    'width': 0.3,
    'height': 0.0,       # height=0 相当于禁用
    'decay_rate': 3.0,
    'power': 2,
}
```

## 调优策略

### 步骤1：确定基线
先禁用自适应，找到合适的全局基线 M 值：
- 太低 = RMSE高
- 太高 = 维度浪费

### 步骤2：降低基线，启用自适应
将基线降低30-50%，然后启用自适应密度

### 步骤3：迭代调整
查看 `adaptive_density_analysis.png`，调整参数直到：
1. 红色增强区域覆盖关键时间段
2. 总维度在可接受范围内
3. RMSE满足精度要求

### 步骤4：精细调优
为不同的信号（q、dq、tau）设置不同的参数：
- Position (q) 通常需要更高精度
- Velocity (dq) 在快速变化区域需要密集点
- Torque (tau) 在接触/碰撞前后需要密集点

## 常见问题

**Q: 为什么我的总维度增加得太多？**
A: 降低 `height` 参数，或减小 `width` 使影响范围更窄。

**Q: 峰值位置不对怎么办？**
A: 调整 `center` 参数。记住它是归一化时间 [0,1]。

**Q: 增强区域太窄/太宽？**
A: 调整 `width` 和 `decay_rate`。增加 width 扩大范围，增加 decay_rate 让衰减更陡。

**Q: 如何知道我设置的参数是否合理？**
A: 查看 `adaptive_density_analysis.png`，红色区域应该平滑且集中在需要的地方。

**Q: 可以设置多个峰值吗？**
A: 当前版本只支持单峰。如需多峰，可以运行多次实验分别针对不同区域。

## 技术细节

### 密度计算方法

1. **基线密度**: 均匀分布，`density = M_base / T`

2. **权重计算**: `weight(t) = 1.0 + density_boost(t)`

3. **归一化**: `normalized_weight = weight / sum(weight)`

4. **自适应密度**: `adaptive_density(t) = normalized_weight * M_adaptive`

这确保了：
- 总控制点数量 = M_adaptive
- 密度在时间上的积分正确
- 保持数值稳定性
