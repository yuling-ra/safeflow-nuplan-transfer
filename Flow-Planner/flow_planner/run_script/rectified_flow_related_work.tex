\noindent\textbf{e) Rectified Flow for Efficient Generative Planning:}
Although flow matching provides a deterministic alternative to diffusion,
accurate numerical integration of the learned velocity field may still
require multiple function evaluations, which becomes costly when planning is
repeated online for several interacting agents. Rectified Flow addresses this
efficiency bottleneck by learning a transport field whose probability paths
are progressively straightened, reducing curvature in the source-to-target
coupling and thereby enabling accurate generation with substantially fewer
ODE integration steps [15], [16]. Iterative reflow further constructs a new
coupling from trajectories generated by a previous flow and retrains the
velocity field on these approximately deterministic pairs, concentrating the
transport along simpler paths [17]. This offers an attractive acceleration
mechanism for safety-constrained generative planners: the learned prior can
retain the multimodal structure of trajectory data while reducing the online
cost of flow integration. However, path straightening alone does not enforce
hard collision, drivable-area, or inter-agent constraints. In particular,
reflow can inherit constraint violations present in the generated coupling,
and few-step integration can amplify errors near rapidly changing safety
boundaries. Rectified Flow should therefore be treated as an efficiency layer
within a constrained planner, with time-varying CBF projection and canonical
constraint representations remaining necessary for formal safety in dynamic
multi-agent environments.
